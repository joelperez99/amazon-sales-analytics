# assets/

Recursos estáticos de la aplicación: logotipos, iconos y hojas de estilo
adicionales.

La aplicación funciona sin ningún archivo en esta carpeta. Si agregas un
logotipo, referéncialo desde `components/layout.py` o desde la configuración de
marca de la organización (**Configuración → Equipo → Personalización de marca**).

Formatos sugeridos:

| Archivo | Uso | Tamaño |
|---|---|---|
| `logo.png` | Encabezado y barra lateral | 240 × 64 px |
| `favicon.png` | Icono de la pestaña | 64 × 64 px |
